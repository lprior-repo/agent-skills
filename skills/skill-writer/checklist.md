# Skill Shipping Checklist

- Frontmatter parses cleanly YAML (`---` markers correct)
- `name` is valid (lowercase letters, numbers, hyphens)
- `description` includes natural trigger language
- Invocation controls match risk profile
- `allowed-tools` is least privilege
- `SKILL.md` is concise and skimmable
- Progressive disclosure links are present and valid
- `$ARGUMENTS` is handled explicitly when parameters are expected
- Output format requirements are clear when consistency matters
- Any scripts referenced are runnable and scoped
